## 2. 문제

1. **두 줄 헤더가 서로 겹친다.** 공통 상단 바 + 도구 안쪽 줄에 같은 기능이 반복: 공유(템플릿 편집기·레이아웃은 안쪽에도), 🔔(보정은 안쪽에도), 테마 ☀(포토·보정·영상 안쪽), 앱 아이콘(포토·벡터 안쪽 메뉴바 맨 앞).
2. **도구마다 버튼 세트·순서가 다르다.** 템플릿 편집기는 공유가 안쪽에, 다른 도구는 위에. "새로 만들기"는 템플릿 편집기에만, "레이어 분리"는 벡터에만 상단에.
3. **"코멘트"와 "0"이 따로**(코멘트 남기기 버튼과 개수 버튼이 나란히) — 역할이 헷갈린다.
4. **텍스트 버튼이 많아 길다** — "딸깍 AI · 템플릿 · 코멘트 · 0 · 공유 · 기록"이 앱 이름 옆에 이어져 파일 이름이 들어갈 자리가 없다(지금 대부분 파일 이름이 안 보임).
5. **좌우 패널을 다 열면 캔버스가 화면의 1/3** — 템플릿(왼쪽 400px) + AI(오른쪽 400px) + 서비스 레일.

## 3. 공통 헤더 구조 (제안)

```
┌───────────────────────────────────────────────────────────────────────────────────────────────┐
│ ‹  [아이콘] 딸깍 포토 ▾ / 가을 신메뉴 포스터 · 저장됨      [도구 슬롯]     ✨ 💬3 🕘 │ 🔔 │ ▷  [내보내기] [공유 •2] │
└───────────────────────────────────────────────────────────────────────────────────────────────┘
   ① 정체성(왼쪽)                                           ② 도구 슬롯   ③ 패널 토글     ④ 알림  ⑤ 결과물(오른쪽 끝)
```

| 영역 | 내용 | 규칙 |
|---|---|---|
| ① 정체성 | ‹ 나가기(딸깍 홈) · 앱 아이콘 · **앱 이름 ▾**(다른 딸깍 도구로 바로 이동 · 새로 만들기) · / · **파일 이름**(더블클릭 이름 바꾸기) · **저장 상태**("저장됨 · 방금" / "저장 중…" / "임시 보관함") | 모든 도구 같음. "새로 만들기"는 앱 이름 ▾ 메뉴 안으로 |
| ② 도구 슬롯 | 그 도구에만 있는 **핵심 행동 1~2개**(벡터 "레이어 분리" 등). 없으면 비움 | 많아지면 도구 안쪽 메뉴로. 상단은 2개까지 |
| ③ 패널 토글(아이콘) | ✨ 딸깍 AI · 💬 코멘트 목록(읽지 않음 배지) · 🕘 기록 — **오른쪽 패널을 여는 버튼은 오른쪽에** | 도구가 지원하는 것만 보인다. 순서 고정 |
| ④ 알림 | 🔔 — AI 작업 완료·멘션 | 도구 안쪽의 🔔는 없앤다 |
| ⑤ 결과물 | ▷ 미리보기/프레젠테이션(지원 시) · **내보내기**(보조 버튼) · **공유**(채운 주요 버튼) · 맨 끝 내 프로필 | **공유가 없는 도구는 내보내기가 주요 버튼**이 된다(아래 4) |

- **템플릿은 상단에서 뺀다.** 왼쪽 패널을 여는 버튼이 오른쪽 위에 있으면 공간이 어긋난다. 도구 왼쪽 패널의 첫 탭으로(UI 디자인의 "파일·에셋·변수" 탭, Canva 왼쪽 사이드바 "디자인·요소·텍스트…"와 같은 방식).
- **저장·테마·🔔·앱 아이콘·공유는 도구 안쪽 줄에서 없앤다.** 저장은 자동 저장 + 상단 저장 상태로, 테마는 설정 › 화면 설정 한 곳.
- **도구 안쪽 메뉴바(파일·편집·…)는 남긴다**(포토·벡터·레이아웃처럼 전문 도구는 메뉴바를 기대한다). 다만 앱 아이콘을 빼고, 상단 헤더와 겹치는 항목(공유·저장·내보내기)은 메뉴에서만.
- 높이: 상단 48px, 도구 안쪽 줄 40px. 상단 바와 도구 줄 사이는 1px 선 하나.

## 5. 사이드바 레일과 프로필

### 서비스 사이드바(접힌 레일) → **도구 안에서는 숨긴다**

- 지금 레일(홈·폴더·즐겨찾기·스토어·…)은 도구 작업 중에 쓰지 않는데 56px을 계속 차지한다.
- Canva·미리캔버스·Figma·CapCut 모두 편집 화면에서는 서비스 메뉴를 숨기고, **나가기(‹ 또는 로고)**로 홈에 간다.
- 다른 도구로 가는 길은 **앱 이름 ▾**(도구 목록)로 대신한다 — 레일보다 바로 간다.
- UI 디자인은 2026-11-19 이미 이렇게 적용했다.

### 프로필 → **오른쪽 끝에 하나만 둔다** (2026-11-19 수정 — 처음엔 뺐다가 사용자 피드백으로 복원)

- 두 곳(상단 아바타 묶음 + 속성 패널)에 있던 걸 **한 곳으로**: 헤더 맨 오른쪽, 공유 다음. Canva·미리캔버스 편집 화면과 같은 자리.
- 메뉴는 짧게: 이름·이메일 · 마이페이지 · 요금제 및 크레딧 · 설정(테마는 여기서).
- 크레딧 잔액·충전은 **프로필 메뉴에서만**(2026-11-19). 프로필 메뉴를 서비스와 같은 것으로 바꾸면서 AI 입력창 아래 "크레딧 N · 충전 ›" 줄은 뺐다. AI 작업 결과의 "크레딧 N 사용"은 그대로.
- 함께 보는 사람은 프로필 옆에 늘어놓지 않고 공유 팝오버 "지금 함께 보는 중"에서만. **공유 버튼에 인원 배지도 두지 않는다**(2026-11-19 피드백).

### 패널 토글 정리 (2026-11-19 피드백)

- **기록(버전 기록)**: 구현 전이라 버튼을 두지 않는다 — 빈 패널을 여는 버튼은 동작 없는 버튼과 같다. 생기면 ③ 자리에 🕘로.
- **딸깍 AI 패널의 대화 목록**은 🕘 대신 말풍선 묶음 아이콘 + "대화 목록" — 버전 기록 🕘와 나란히 보여 같은 기능처럼 읽히던 문제.
- **홈 탭**(파일 없음)에서는 파일 단위 토글(코멘트)을 숨기고 ✨ AI만.

## 6. 적용 순서(제안)

1. `EditorHeader`에 기능 조합을 넘기는 방식 추가(`capabilities: { ai, comments, history, present, export, share }`, `toolSlot`, `saveState`, 앱 전환 ▾).
2. 템플릿 편집기 5종(같은 화면이라 한 번에) — 안쪽 공유·저장·내보내기를 위로 올리고 템플릿을 왼쪽 탭으로.
3. 포토·벡터·레이아웃 — 안쪽 메뉴바의 앱 아이콘·테마 정리, 공유·내보내기 위로.
4. 보정·영상편집 — 내보내기를 주요 버튼으로, 안쪽 🔔·테마 제거.
5. 공통: 서비스 레일 숨김, 프로필은 오른쪽 끝 하나(서비스와 같은 메뉴, 크레딧 포함).

## 7. UI 디자인 적용 내용 (2026-11-19)

- `EditorHeader` props: `currentAppId` · `onSwitchApp` · `onNewFile` · `saveState` · `capabilities { present, export, share }` · `presentLabel` · `onExport` · `toolSlot` · `actions`(DockButtons) · `viewers`.
- 앱 이름 ▾ = 도구 목록(`editor-shell/apps.ts`, 홈 도구모음과 같은 분류) + 맨 위 "새 파일". 이 프로젝트에 있는 편집기(한글·문서·시트·슬라이드·포토·영상)는 바로 열고, 없는 도구(벡터·보정·레이아웃·템플릿 편집기 5종·PDF)는 "준비 중" 안내만 — 에디터는 닫지 않는다.
- 저장 상태(2026-11-19 간소화): 평소엔 파일 이름 옆 **구름 아이콘만**, 위치·시각("임시 보관함에 저장됨 · 방금")은 툴팁. 글자는 "저장 중…"·"저장 못 함"일 때만. 안쪽 에디터가 저장 상태를 보여 주는 도구(한글·워드)는 헤더에 두지 않는다.
- UI 디자인 기능 조합: ▷ 프레젠테이션 · 공유(주요). 내보내기는 메인 메뉴에만(준비 중)이라 헤더에 버튼 없음. 도구 슬롯 없음.
- 크레딧: 프로필 메뉴의 크레딧 카드에서만 보여 준다(AI 입력창 아래 잔액·충전 줄은 2026-11-19에 뺌).
- 프로필: 헤더 오른쪽 끝 하나. **메뉴는 서비스 상단바와 같은 컴포넌트** `components/account/ProfileMenuButton`(2026-11-19, 크레딧 카드·튜토리얼·문의·커뮤니티·로그아웃까지 동일). 다른 화면으로 가는 항목(마이페이지·요금제 및 크레딧·튜토리얼)은 에디터를 닫고 가고, 설정·크레딧 내역은 에디터 위에 설정 모달. 공유 버튼 인원 배지 없음. 기록 버튼 없음(구현 전). 홈 탭은 ✨만.

- **딸깍 AI는 글자 버튼(2026-11-19)**: 핵심 기능이라 아이콘(✨)만 두면 잘 안 보인다는 피드백. 패널 토글 중 AI만 "✨ 딸깍 AI" 글자 버튼(`DockTab.emphasized`)으로,
  닫혀 있어도 브랜드 연한 바탕·파란 글자로 보이고 열리면 파란 테두리. 코멘트 목록은 아이콘 그대로. Canva "Canva AI"·Notion "Notion AI"처럼 이름을 함께 둔 방식.

## 8. 아이콘 버튼 툴팁 (2026-11-19)

- **글자 없이 아이콘만 있는 버튼은 모두 툴팁**을 단다 — 기존 디자인 시스템의 `viewer/IconTooltip`(`ui/tooltip` 래퍼, theme.css `--tooltip-*` 토큰: 근검정 바탕·흰 글자·0.4초 지연·화면 끝에서 자동으로 뒤집힘). 브라우저 기본 `title`은 함께 쓰지 않는다(툴팁이 두 개 뜸).
- 문구 = **무엇을 하는지 + 단축키**: "딸깍 AI 열기/닫기 (⌘J)", "프레임 (F)", "왼쪽 패널 숨기기 (⌘\)", "보내기 (Enter)". 메뉴를 여는 버튼은 안에 든 것을 적는다: "더 보기 — 열기 · 이름 바꾸기 · 복제 · 삭제".
- 위치: 기본 아래. 화면 아래쪽에 있는 것(하단 툴바·입력창·대기열)은 위로, 오른쪽 아래 ? 는 왼쪽으로.
